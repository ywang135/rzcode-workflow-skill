# rzcode 软著文档生成 Skill

面向真实软件代码拥有者，在**不上传代码到软宝宝**的前提下，通过 rzcode-mcp 在本地安全生成高质量软件著作权登记文档。

---

## 软宝宝能为你做什么？

[软宝宝](https://rzcode.vip) 是一款面向真实软件代码拥有者的软著申请文件生成工具。它基于你的**真实项目代码**和**真实软件截图**，帮助你快速整理并生成软著申请所需材料：

- ✓ 源代码文档
- ✓ 软件使用手册
- ✓ 登记申请帮助表格

在软著申请规则逐步收紧的当下，传统“AI 凭空生成代码和截图”的方式面临较高的重复检索风险。软宝宝更适合真正拥有软件项目的用户，在新规则下高效生成符合申请场景的文档材料。

---

## 为什么推荐这个 Skill？

很多开发者或代理机构拥有真实的本地项目，但担心把代码上传到第三方平台。本 Skill 充分利用 **rzcode-mcp** 的能力，让你的代码始终留在本地：

- **代码不上云**：仅上传项目元信息（如功能模块、技术栈、运行环境），不传输完整源代码。
- **文档质量更高**：结合真实代码和真实截图，生成内容更贴合实际项目，降低申请补正风险。
- **操作自动化**：在本地分析代码、生成润色内容，并通过 MCP 工具同步到软宝宝，由软宝宝完成最终排版与 `.docx` 输出。
- **截图可本地上传**：提供本地脚本 `rzcode-workflow-skill/scripts/upload_image_files.py`，支持 `.png`、`.jpg`、`.jpeg`、`.svg`，由脚本完成目录遍历、base64 编码和 `rzcode_upload_images` 上传，避免把图片内容加载到 LLM 上下文；上传时还可为图片附加 `type`、`diagram_type`、`diagram_description` 等元信息。

---

## 核心价值

- **省时**：将原本耗时较长的文档整理、截图匹配、排版工作自动化完成。
- **安全**：核心代码始终保留在本地，不上传到软宝宝服务器。
- **省心**：针对真实项目生成内容，更符合软著申请对“真实性”的要求。

> 在常见项目场景下，软宝宝可以帮助你节省 **90% 以上** 的文档准备时间。

---

## 适用场景

- 你有一个真实的软件项目，希望申请软件著作权。
- 你不想把完整源代码上传到任何在线平台。
- 你需要生成代码文档、软件使用手册或登记申请帮助表格。
- 你希望将本地截图与代码内容结合，生成更真实的申请资料。

---

## 本 Skill 能生成的文档

| 文档 | 是否需要 source_code_meta | 是否需要截图 | 说明 |
| --- | --- | --- | --- |
| 源代码文档 | 否 | 否 | 在本地分析代码并按规则生成，代码不上传。 |
| 软件使用手册 | 是 | 是 | 结合项目元信息和截图，生成符合申请场景的手册内容。 |
| 登记申请帮助表格 | 是 | 否 | 基于项目元信息生成申请信息表，留档备用。 |

---

## 快速开始

1. 确保 rzcode-mcp 已配置并连接（见下方配置说明）。
2. 提供一个本地代码文件夹路径。
3. 选择或创建一个 rzcode 本地项目。
4. 根据目标文档执行对应分支：
   - “软件使用手册” → 上传截图、润色内容，然后生成并下载使用手册。
   - “登记申请帮助表格” → 基于项目元信息生成表格并下载。
   - “源代码文档” → 按规则在本地生成源代码文档。
   - “全部生成” → 按使用手册 → 申请表格 → 源代码顺序依次生成。

## 环境要求

1. rzcode-mcp 已配置并连接。
2. 用户已在 [rzcode.vip](https://rzcode.vip) 注册并生成 API key。

### MCP 配置示例

```json
{
  "mcpServers": {
    "rzcode-mcp": {
      "type": "http",
      "url": "https://rzcode.vip/mcp",
      "headers": {
        "X-API-Key": "<API key>"
      }
    }
  }
}
```

> 服务端 `/mcp` 统一支持 POST 请求与 GET/DELETE 会话管理。若客户端未发送 `MCP-Protocol-Version` 请求头，服务端会按 MCP 规范回退到 `2025-03-26`，无需手动在 headers 中声明。

## 统一准备流程

1. 检查 rzcode-mcp 配置与 API key。
2. 确认本地代码文件夹。
3. 选择或创建本地协作项目。
4. 按需上传项目元信息（source_code_meta），不含完整源代码。

详细步骤与工具参数请参考 [`SKILL.md`](SKILL.md)。

---

## 分支文档生成流程

### 软件使用手册

1. 上传软件截图（可网页端一次性上传，或使用本地脚本批量上传）。
2. 等待图片内容提取完成，按提示润色截图说明。
3. 选择生成方式：网页端点击生成，或调用 MCP 工具创建任务。
4. 等待任务完成，下载 `.docx`。

### 登记申请帮助表格

1. 确认已有项目元信息。
2. 选择生成方式：网页端点击生成，或调用 MCP 工具创建任务。
3. 等待任务完成，下载 `.docx`。

### 源代码文档

1. 获取源代码文档规则。
2. 在本地按规则生成并输出 `.docx`。

---

## 输出文件

- 软件使用手册：`{project_name}_软件使用指南.docx`
- 登记申请帮助表格：`{project_name}_申请表辅助数据.docx`
- 源代码文档：`{project_name}_源代码.docx`

---

## 注意事项

- 截图文件名建议使用英文、数字、下划线，避免中文或特殊字符。
- 截图上传后会自动触发图片内容解析任务。任务完成或彻底失败前无法再次上传，请一次性上传所有需要的截图。
- 源代码文档提取时，应跳过依赖、构建产物和日志等非业务代码。
- 全程依赖 rzcode-mcp，请确保 MCP 已正确连接。
